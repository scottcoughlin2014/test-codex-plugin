## Description

Four individual data sets, each containing customer buying history for about 100,000 customers of nationally known catalog and non-profit database marketing businesses.

Corporate names are anonymous and customer names and addresses have been removed, but the business type is indicated. ZIP codes have been retained (if possible) to provide a potential link to Census ZIP level demographics.

## Access

These data are available via [Wharton Research Data Services](https://wrds-web.wharton.upenn.edu) (WRDS). WRDS offers both a web interface, for small interactive queries, and the Linux-based WRDS Cloud for running batch programs. A temporary class account and password to the WRDS web interface may be requested by faculty members for instructional use in the context of a course.
