## Description

FTSE/Russell provides comprehensive coverage of equity and fixed income markets:

-   Monthly Index Holdings: Russell Indexes for each closing day (Comparable to Comp Index Constituent History)
-   Monthly Contributions to Return: Analysis of each sector and industry contributing to the overall return of a Russell Index (Comparable to Comp Index Prices)
-   Monthly Historical Sector Weights: Sector weight history (All Indexes)

## Access

These data are available via [Wharton Research Data Services](https://wrds-web.wharton.upenn.edu) (WRDS). WRDS offers both a web interface, for small interactive queries, and the Linux-based WRDS Cloud for running batch programs.
