## Description

```html
<p><b>Board Analyst</b> is a source of comprehensive objective corporate governance, compensation, and critical company information. It covers 1500 to 3000 firms (depending on the year) from 2001 to 2006 and over 45,000 corporate executives and directors.</p>
        <p>The Corporate Library offers annual historical data captures from <b>Board Analyst</b> for each proxy year beginning in 2001. Information includes:</p>
        <ul>
          <li>Corporate Board Structure and Independence</li>
          <li>Director Positions and Committee Assignments</li>
          <li>Executive Compensation</li>
          <li>Director Compensation</li>
          <li>Audit Fees</li>
          <li>Corporate Ownership</li>
          <li>Takeover Defenses</li>
        </ul>
        <p>Among other things, it includes such fields as SOX compliance, the existence of a code of ethics, the identity of the "financial expert" on the audit committee, some litigation information, etc.</p>
```

## Access

These data are available via [Wharton Research Data Services](https://wrds-web.wharton.upenn.edu) (WRDS). WRDS offers both a web interface, for small interactive queries, and the Linux-based WRDS Cloud for running batch programs. A temporary class account and password to the WRDS web interface may be requested by faculty members for instructional use in the context of a course.
